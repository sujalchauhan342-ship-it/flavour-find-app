# 🍴 Flavour Find

Flavour Find is a responsive recipe discovery web application built using HTML, CSS, and JavaScript. Users can search for different foods and view recipes, ingredients, cooking instructions, category, and cuisine.

## ✨ Features

- 🔍 Search recipes by food name
- 🍕 Recipe images
- 📝 Complete ingredients list
- 👨‍🍳 Cooking instructions
- 🌎 Recipe category and cuisine
- 📱 Responsive design
- ❌ Error handling
- ⚡ Fast recipe search using an API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- TheMealDB API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html`.
4. Run it using Live Server.
5. Enter a food name in the search box.
6. Click **Search** to find recipes.

## 🌐 API

This project uses **TheMealDB API** to fetch recipe information.

The API provides recipe details such as:

- Recipe name
- Food image
- Category
- Cuisine
- Ingredients
- Measurements
- Cooking instructions
